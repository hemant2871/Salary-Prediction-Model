# 🤖 Salary Prediction Model – AI/ML Project

This project is an **AI & Machine Learning based Salary Prediction Model** developed as a **task during an AICTE Virtual Internship**.  
The model predicts salary based on given input features using **machine learning algorithms**.

---

🔗 **Live Demo:** [Click Here](https://salary-prediction-model-wtqflt6plsqrlappbyhemant.streamlit.app/)


## 🧠 About the Project

The main goal of this project is to understand the complete **machine learning workflow**, including:
- Data preprocessing
- Model training
- Prediction
- Performance evaluation

This project was completed as part of a **virtual internship task under AICTE**.

---
